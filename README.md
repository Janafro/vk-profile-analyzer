# vk-profile-analyzer
Инструмент на Python для сбора и OSINT-анализа публичных данных пользователей VK API.
ЧТО СДЕЛАТЬ ПЕРЕД ЗАПУСКОМ
____________________
1. УСТАНОВКА БИБЛИОТЕКИ

Перед запуском скрипта нужно скачать библиотеку vk_api в терминале
py -m pip install vk_api

2. ПОЛУЧЕНИЕ ТОКЕНА VK API
Нужен сервисный ключ доступа, для того, чтобы его получить, нужно:
1) Перейти на официальный портал разработчиков VK: dev.vk.com и войти под своим аккаунтом;
2) В правом верхнем углу перейти в раздел «Мои приложения» и нажать «Создать приложение»;
3) Ввести название, выбрать тип «Мини-приложение» и сохранить настройки;
4) В левом меню перейти в раздел «Настройки» и найти поле «Сервисный ключ доступа», скопировать его.
5) Ввести его в строчку ACCESS_TOKEN = "Сюда вводить токен"

!!Токен нельзя выкладывать в открытый доступ!!

3. ЗАПУСТИТЬ СКРИПТ
В терминал ввести:
py "Расположение файла" 
ИЛИ
py проверкаВК.py
